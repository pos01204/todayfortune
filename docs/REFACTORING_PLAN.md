## 🔧 리팩토링 항목

### 1. 로딩 페이지 개선 (Priority: High) ⭐

**문제점**
```
현재: 로딩 GIF(흰 배경) + 페이지(크림색 배경) = 어색함
목표: 로딩 GIF(흰 배경) + 페이지(흰 배경) = 자연스러움
```

**수정 계획**

| 위치 | 현재 | 변경 |
|------|------|------|
| 홈 로딩 상태 | `bg-cream` | `bg-white` |
| 결과 로딩 상태 | `bg-cream` | `bg-white` |
| 로딩 오버레이 | `bg-white/90` | `bg-white` |
| 로딩 애니메이션 | 단순 float | 부드러운 페이드 + 텍스트 변화 |

**로딩 화면 디자인**
```
┌─────────────────────────────────┐
│                                 │
│                                 │
│         [ 로딩 GIF ]            │  ← 흰 배경에 자연스럽게
│                                 │
│    "취향을 찾고 있어요..."       │  ← 텍스트 애니메이션
│                                 │
│         · · ·                   │  ← 점 애니메이션
│                                 │
└─────────────────────────────────┘
       bg-white (순백색)
```

### 2. UI/UX 완성도 개선 (Priority: High)

#### 2-1. 인트로 화면 개선

| 항목 | 현재 | 개선 |
|------|------|------|
| 연도 표기 | "2024 새해 특별 이벤트" | "2026 새해 특별 이벤트" (동적) |
| 입력 필드 | 기본 스타일 | 포커스 시 라벨 이동 (Floating Label) |
| 에러 메시지 | 빨간 텍스트만 | 아이콘 + 부드러운 애니메이션 |
| 버튼 | 단순 그라데이션 | 로딩 시 스켈레톤 효과 |

#### 2-2. 결과 화면 개선

| 항목 | 현재 | 개선 |
|------|------|------|
| 헤더 | 텍스트만 | 아이디어스 로고 + 뒤로가기 |
| 점수 바 | 단색 | 그라데이션 + 숫자 카운트업 |
| 키워드 뱃지 | 클릭 가능 표시 없음 | 터치 힌트 + 펄스 효과 |
| 작품 카드 | 목업 이미지 | 실제 이미지 로드 실패 시 플레이스홀더 |
| 공유 버튼 | 고정 위치 | 스크롤 시 하단 고정 (Sticky) |

#### 2-3. 마이크로 인터랙션

```css
/* 추가할 인터랙션 */
- 버튼 호버 시 미세한 그림자 확장
- 카드 터치 시 subtle scale 효과
- 점수 로딩 시 왼쪽에서 채워지는 애니메이션
- 키워드 뱃지 순차 등장 (stagger)
- 스크롤 시 패럴랙스 효과 (별 장식)
```

### 3. 반응형 디자인 강화 (Priority: Medium)

```css
/* 브레이크포인트 */
@media (max-width: 320px) { /* 아이폰 SE */ }
@media (max-width: 375px) { /* 아이폰 미니 */ }
@media (max-width: 428px) { /* 아이폰 프로 맥스 */ }
@media (min-width: 768px) { /* 태블릿 */ }
```

| 화면 | 현재 | 개선 |
|------|------|------|
| 아이폰 SE (320px) | 일부 깨짐 | 폰트/패딩 조정 |
| 태블릿 (768px+) | 모바일과 동일 | 2컬럼 레이아웃 |
| 데스크톱 | 모바일과 동일 | 최대 너비 제한 + 중앙 정렬 |

### 4. 접근성 개선 (Priority: Medium)

| 항목 | 현재 | 개선 |
|------|------|------|
| 색상 대비 | 일부 미흡 | WCAG AA 기준 충족 |
| 키보드 네비게이션 | 미지원 | Tab 순서 + 포커스 링 |
| 스크린 리더 | aria 미적용 | aria-label, role 추가 |
| 폼 라벨 | 기본 연결 | htmlFor 명시적 연결 |
| 이미지 alt | 일부 누락 | 모든 이미지 alt 추가 |

```tsx
// 접근성 개선 예시
<button
  aria-label="운세 결과 공유하기"
  role="button"
  tabIndex={0}
>
```

### 5. 성능 최적화 (Priority: Medium)

#### 5-1. 이미지 최적화

| 항목 | 현재 | 개선 |
|------|------|------|
| 로딩 GIF | 원본 그대로 | WebP 변환 또는 Lottie |
| 브랜드 에셋 | PNG | WebP + blur placeholder |
| 이미지 로딩 | 즉시 로드 | lazy loading |

#### 5-2. 코드 최적화

```typescript
// 현재
import { motion } from 'framer-motion'

// 개선: 동적 임포트
const motion = dynamic(() => import('framer-motion').then(m => m.motion))
```

| 항목 | 현재 | 개선 |
|------|------|------|
| 번들 크기 | 전체 로드 | 코드 스플리팅 |
| 애니메이션 | framer-motion 전체 | 필요한 것만 import |
| 폰트 | 변수 폰트 전체 | subset 폰트 |
