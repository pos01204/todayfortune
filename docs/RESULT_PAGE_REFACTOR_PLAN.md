# 🎯 결과 페이지 리팩토링 기획안 (https://todayfortune-smoky.vercel.app/result)

> 목적: 결과 페이지의 **완성도/전환율/브랜딩 일관성**을 한 단계 업그레이드

---

## 1) 현황 스냅샷

### 현재 확인된 내용
- 로딩 화면: 텍스트 중심, UI는 간결함
- 핵심 액션: 결과 로딩 이후 탐색 및 구매 유도 동선
- 개선 방향: **로딩 이후 전환 흐름, 디테일, 신뢰 요소 강화**

---

## 2) 개선 목표

| 목표 | 설명 |
|------|------|
| 전환율 상승 | 결과 → 아이디어스 이동률 증가 |
| 몰입감 강화 | 운세/취향 메시지의 스토리텔링 확장 |
| 신뢰도 강화 | “작가/작품”의 신뢰 요소 노출 |
| 브랜드 일관성 | 아이디어스 감성 정교화 |

---

## 3) 리팩토링 전략

### 3-1. 로딩 → 결과 전환 UX 강화

**현재**: 로딩 후 바로 결과 화면  
**개선**: 자연스러운 전환을 위한 **단계형 리빌(Progressive Reveal)**

```
[로딩 GIF] → [메인 메시지 1차 노출] → [점수/키워드] → [작품 카드] → [CTA 고정]
```

**추가 요소**
- 로딩 중 “브랜드 메시지 스니펫” 2~3개 순환
  - 예: “아이디어스에는 3만 명 이상의 작가가 있어요”
  - 예: “오늘의 키워드는 자정에 새로 바뀌어요”

---

### 3-2. 메인 메시지 몰입감 강화

**현재**: 단문 위주 메시지  
**개선**: “나의 취향 스토리” 구조로 재구성

```
✦ {이름}님의 오늘 ✦

"오늘은 새로운 취향을 발견하기 좋은 날이에요.
당신의 감각이 이끄는 곳에 특별한 작품이 있어요."

→ 아래에서 바로 작품을 만나보세요
```

추가 옵션:
- 메시지 하단에 “아이디어스 운세” 서명
- 문장 길이를 2~3줄로 고정해 가독성 유지

---

### 3-3. 키워드 영역 → 구매 입구로 전환

**목표**: 키워드를 “정보”가 아닌 “쇼핑 입구”로 변환

```
🎨 오늘의 컬러
코랄 핑크 · 작품 847개 →

✋ 끌리는 소재
천연 가죽 · 작품 1,234개 →

💝 취향 카테고리
주얼리/액세서리 · 인기 작품 보러가기 →
```

**개선 포인트**
- 키워드 옆에 작품 수 표시 (가상 카운트도 OK)
- 키워드 클릭 힌트 문구/애니메이션 추가
- 키워드 조합 CTA (핑크 + 가죽)

---

### 3-4. 작품 카드 전환 강화

**현재**: 카드 리스트 위주  
**개선**: “구매 심리 요소” 삽입

```
[BEST] 천연 가죽 미니 지갑
₩35,000  17% OFF
❤️ 2,341명이 찜함 · ★ 4.9
[🧡 아이디어스에서 보기 →]
```

**개선 포인트**
- BEST/인기 뱃지
- 찜 수 / 평점 표시
- “아이디어스에서 보기” CTA 강조

---

### 3-5. 하단 고정 CTA (Sticky)

스크롤 위치와 무관하게 **항상 구매 동선 노출**

```
┌────────────────────────────────┐
│ 🧡 아이디어스에서 작품 보기     │
│ [카테고리]                      │
└────────────────────────────────┘
```

```
로딩
  ↓
메인 메시지 (스토리)
  ↓
점수/키워드
  ↓
추천 작품 + 조합 검색 CTA
  ↓
카테고리 이동
  ↓
고정 CTA
```

## 5) 비주얼/브랜딩 업그레이드

- 톤: “정성”, “발견”, “따뜻함”
- 강조색: idus orange + soft cream
- 패턴: brand pattern 은은하게 적용
- CTA 문구: “작품 보기”, “아이디어스에서 보기”
