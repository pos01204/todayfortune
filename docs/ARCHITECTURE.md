# 🧡 아이디어스 "오늘의 취향 운세" 이벤트

## 브랜드 컨셉: 아이디어스다움을 담다

> "나만의 이야기를 만들어가고, 나도 몰랐던 취향을 발견하고, 
> 비슷한 가치를 나누는 사람과 소통하는 특별한 일상"

단순한 운세가 아닌, **취향을 발견하는 여정**으로 재해석합니다.

---

## 1. 기획 의도

### 왜 "오늘의 취향 운세"인가?

아이디어스의 핵심 가치는 **"사람과 사람을 잇다"**입니다. 
이 이벤트는 단순히 오늘의 운을 점치는 것이 아니라:

- **STORY (나만의 이야기)**: 생년월일로 시작되는 나만의 취향 이야기
- **DISCOVERY (취향의 발견)**: 나도 몰랐던 취향을 발견하는 기쁨
- **CONNECTION (따뜻한 소통)**: 작가의 정성이 담긴 작품과의 연결

### 타겟 고객: 'US'

> "다른 건 다 포기해도 ______ 만은 포기 못해!"

일상에서 놓치고 싶지 않은 취향을 디깅(digging)하는 **선택적 덕후 & 까탈리스트**

### 톤 & 보이스

**DO ✅**
- 따뜻하고 친근한 말투
- "작품"이라는 표현 사용 (상품 X)
- 작가의 정성과 이야기 강조
- 취향과 발견의 즐거움 전달

**DON'T ❌**
- 최저가, 빠른 배송 강조
- 상품, 물건이라는 표현
- 차갑고 기계적인 톤
- 과도한 할인/프로모션 강조

## 4. 취향 운세 카테고리

기존의 금전/직장/애정 대신, **아이디어스다운 취향 카테고리**로 재구성:

| 카테고리 | 아이콘 | 의미 | 설명 |
|---------|--------|------|------|
| 🎨 창작 에너지 | 팔레트 | 만들기 욕구 | 오늘 새로운 것을 만들고 싶은 정도 |
| 💝 선물 운 | 선물상자 | 마음 전하기 | 소중한 사람에게 마음을 전하기 좋은 정도 |
| 🔍 발견 운 | 돋보기 | 취향 탐색 | 새로운 취향을 발견할 가능성 |
| 💕 인연 운 | 하트 | 작가와의 만남 | 특별한 작가/작품과의 인연 |
| ✨ 영감 지수 | 별 | 일상의 영감 | 일상에서 영감을 받을 가능성 |

## 5. 취향 키워드

### 오늘의 컬러
아이디어스 작품에서 자주 볼 수 있는 감성적인 컬러:

| 컬러명 | HEX | 연결 카테고리 |
|--------|-----|---------------|
| 코랄 핑크 | #FF7F7F | 주얼리, 패션 |
| 민트 그린 | #98FF98 | 홈데코, 플랜트 |
| 테라코타 | #E2725B | 도자기, 공예 |
| 크림 베이지 | #F5F5DC | 가죽, 패브릭 |
| 인디고 블루 | #4B0082 | 천연염색, 텍스타일 |

### 끌리는 소재
핸드메이드 감성이 느껴지는 소재들:

- 천연 가죽 → 가방, 지갑, 소품
- 스털링 실버 → 주얼리, 액세서리
- 도자기/세라믹 → 그릇, 화병, 오브제
- 천연 목재 → 문구, 가구, 소품
- 핸드메이드 글라스 → 조명, 데코
- 오가닉 패브릭 → 의류, 홈텍스타일

### 취향 카테고리
아이디어스 대표 카테고리와 연결:

```
주얼리/액세서리 → 나만의 스타일을 완성하는
홈데코/리빙 → 공간에 온기를 더하는
문구/다이어리 → 일상을 기록하는
푸드/식품 → 정성을 맛보는
아트/일러스트 → 감성을 소장하는
```
