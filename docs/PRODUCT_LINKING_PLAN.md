# 🎁 오늘의 취향에 어울리는 작품 - 실제 연동 기획서

> 운세 결과 페이지의 추천 작품을 실제 아이디어스 작품/검색 결과와 연결하는 방안

---

## 📋 현황 분석

### 현재 상태
| 항목 | 현재 | 목표 |
|------|------|------|
| 작품 이미지 | 목업 이미지 | 실제 아이디어스 작품 이미지 |
| 작품명 | 생성된 텍스트 | 실제 작품명 |
| 가격 | 임의 가격 | 실제 판매 가격 |
| 클릭 시 | 검색 결과 페이지 | **실제 작품 상세 페이지** |

### 현재 연결 방식
```
키워드 "천연 목재" + "크림 베이지"
    ↓
https://www.idus.com/v2/search?keyword=원목%20베이지
    ↓
검색 결과 페이지 (여러 작품 리스트)
```

## 🎯 연동 방안 비교

### 방안 1: 검색 결과 페이지 연결 (현재)

```
[추천 작품 카드] → 아이디어스 검색 결과 페이지
```

**장점**
- ✅ API 연동 불필요
- ✅ 항상 최신 작품 노출
- ✅ 품절/삭제 작품 이슈 없음
- ✅ 즉시 구현 가능

**단점**
- ❌ 특정 작품 지정 불가
- ❌ 썸네일/가격이 실제와 다름
- ❌ 사용자 경험 일관성 부족

**URL 패턴**
```
https://www.idus.com/v2/search?keyword={키워드}
https://www.idus.com/v2/search?keyword=가죽%20핑크
```

---

### 방안 2: 카테고리 + 필터 검색 연결 ⭐ 권장

```
[추천 작품 카드] → 카테고리 페이지 (정렬/필터 적용)
```

**장점**
- ✅ API 연동 불필요
- ✅ 카테고리별 정확한 작품 리스트
- ✅ 인기순/최신순 정렬 가능
- ✅ 실제 카테고리 구조 활용

**URL 패턴**
```
# 카테고리 + 정렬
https://www.idus.com/v2/category/1047?sort=popular

# 카테고리 + 검색어 조합
https://www.idus.com/v2/category/1047?keyword=실버

# 카테고리 ID 목록
1046: 식품/디저트
1047: 주얼리/액세서리  
1048: 패션/잡화
1049: 홈리빙/인테리어
1050: 케이스/문구
1051: 뷰티/향기
1052: 반려동물
1053: 영유아/출산
1054: 공예/DIY
```

### 방안 3: 실제 작품 ID 직접 연결 (API 필요)

```
[추천 작품 카드] → 실제 작품 상세 페이지
```

**장점**
- ✅ 정확한 작품 1:1 매칭
- ✅ 실제 이미지/가격/작가 표시
- ✅ 최고의 사용자 경험

**단점**
- ❌ 아이디어스 API 연동 필요
- ❌ 작품 품절/삭제 시 대응 필요
- ❌ 개발 복잡도 증가
- ❌ API 권한/계약 필요

**URL 패턴**
```
https://www.idus.com/v2/product/{product_id}
예: https://www.idus.com/v2/product/123456
```


**장점**
- ✅ 브랜딩 일관성 유지

```
https://www.idus.com/v2/event/{event_id}
```

## ✅ 권장 구현 방안

### Phase 1: 즉시 적용 (API 없음)

**키워드 기반 스마트 검색 URL 생성**

```typescript
// 키워드 조합으로 정교한 검색 URL 생성
function generateProductUrl(keywords: LuckyKeywords): string {
  const { color, material, category } = keywords
  
  // 카테고리 URL 기본값
  const categoryId = CATEGORY_MAP[category.value] // 1047, 1048 등
  
  // 검색어 조합
  const searchTerms = [
    COLOR_SEARCH_MAP[color.value],      // "핑크", "민트" 등
    MATERIAL_SEARCH_MAP[material.value] // "가죽", "실버" 등
  ].filter(Boolean).join(' ')
  
  // 카테고리 + 검색어 조합 URL
  if (categoryId && searchTerms) {
    return `https://www.idus.com/v2/category/${categoryId}?keyword=${encodeURIComponent(searchTerms)}&sort=popular`
  }
  
  // 검색어만 있는 경우
  return `https://www.idus.com/v2/search?keyword=${encodeURIComponent(searchTerms)}`
}
```

**UI 개선**
```
┌─────────────────────────────────────────┐
│  🎁 오늘의 취향에 어울리는 작품          │
│  작가의 정성이 담긴 특별한 작품들을 만나보세요 │
├─────────────────────────────────────────┤
│  ┌──────┐ 천연 목재 작품 컬렉션         │
│  │ 🪵  │ "원목" 키워드 인기 작품 보기   │ → 검색 결과
│  └──────┘ 끌리는 소재 매칭              │
├─────────────────────────────────────────┤
│  ┌──────┐ 크림 베이지 컬러 작품         │
│  │ 🎨  │ "베이지" 키워드 인기 작품 보기 │ → 검색 결과
│  └──────┘ 오늘의 컬러 매칭              │
├─────────────────────────────────────────┤
│ [  주얼리/액세서리 작품 더 보기 →  ]    │ → 카테고리 페이지
└─────────────────────────────────────────┘
```

## 💡 결론

**현재 단계에서 최선의 방안:**

1. **검색어 조합 URL** 사용 (API 불필요)
2. 키워드별 **최적화된 검색어** 매핑
3. **카테고리 페이지** 연결로 정확한 작품군 노출
4. UI에 **"아이디어스에서 찾아보기"** 명확히 표시

```
사용자 운세 확인
    ↓
오늘의 컬러: 코랄 핑크 / 끌리는 소재: 천연 가죽
    ↓
추천 작품 클릭
    ↓
https://www.idus.com/v2/search?keyword=핑크%20가죽&sort=popular
    ↓
실제 아이디어스 검색 결과에서 작품 구매
```

이 방식으로 **API 연동 없이도** 사용자를 실제 아이디어스 작품으로 자연스럽게 연결할 수 있습니다! 🧡
