## 📊 서비스 목표 정의

### KPI (핵심 성과 지표)

| 지표 | 설명 | 목표 |
|------|------|------|
| **CTR (클릭률)** | 작품/키워드 클릭 → 아이디어스 이동 | 40%+ |

## 🔥 Phase 1: 전환율 극대화 (핵심)

### 1-1. CTA 버튼 강화

**현재 문제점**
- CTA가 눈에 띄지 않음
- 클릭 유도 문구 부족
- 버튼이 화면 하단에 묻힘

**개선안**

```
┌─────────────────────────────────────────┐
│  🎁 오늘의 취향에 어울리는 작품          │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ [BEST] 천연 가죽 작품 컬렉션     │   │
│  │        35,000원                 │   │
│  │ ┌─────────────────────────┐    │   │
│  │ │ 🧡 아이디어스에서 보기 →  │    │   │  ← NEW: 명확한 CTA
│  │ └─────────────────────────┘    │   │
│  └─────────────────────────────────┘   │
│                                         │
│  ┌─────────────────────────────────────┐│
│  │  🔥 지금 이 작품들이 인기예요!      ││  ← NEW: 긴급성 유발
│  │  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ││
│  │  [주얼리/액세서리 인기작품 보러가기] ││  ← NEW: 카테고리 직접 이동
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

**CTA 문구 개선**

| 현재 | 개선 |
|------|------|
| "작품 더 보기" | "🔥 인기 작품 구경하기" |
| "아이디어스" (작은 텍스트) | "🧡 아이디어스에서 보기 →" |
| 없음 | "오늘만 특별 할인 중!" (뱃지) |
| 없음 | "1,234명이 찜했어요" (소셜 프루프) |

## 🎯 핵심 요약

### 전환율 향상을 위한 5가지 핵심

| # | 요소 | 적용 |
|---|------|------|
| 1 | **명확한 CTA** | "아이디어스에서 보기 →" 버튼 강화 |
| 2 | **긴급성 (FOMO)** | "오늘의 추천은 자정에 바뀌어요" |
| 3 | **소셜 프루프** | "1,234명이 찜함", 평점 표시 |
| 4 | **개인화** | "95% 매칭", "당신의 취향 점수" |
| 5 | **발견의 즐거움** | "핑크 가죽 조합 작품 23개 발견!" |

### 사용자 행동 유도 Flow

```
운세 확인 → 키워드에 흥미 → 작품 수 확인 → 클릭 → 아이디어스 → 구매/찜
     ↓              ↓              ↓          ↓
   몰입감      발견의 즐거움    긴급성/FOMO   명확한 CTA
```
